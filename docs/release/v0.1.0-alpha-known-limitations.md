# v0.1.0-alpha Known Limitations

This release is a `Developer Preview` and not intended for production operation.

## Product Positioning Limits

- UX polish is not a goal in `v0.1.0-alpha`.
- API/contract details may evolve before stable release.
- Backward compatibility guarantees are limited at this stage.

## GUI and Host Limits

- No full-featured GUI product is included in core.
- Core ships only a minimum reference host:
  - `docs/default-gui-host.html`
- No automated browser-level GUI E2E suite is included yet.
- Bridge conformance is tested, but rich rendering behavior is host-owned.

## Runtime / Tooling Limits

- Focus is CLI-first (`validate/compile/run/trace`).
- Advanced plugin ecosystems and long-tail adapters are incomplete.
- Some operational hardening remains scoped for later milestones.

## Scope Boundaries for This Release

- Out of scope:
  - commercial-grade UI/UX,
  - complete automatic E2E for GUI presentation,
  - finalized plugin extension surface,
  - production remote distribution/operations model.

## Support Boundary

- Supported:
  - core runtime behavior defined by current specs and gates,
  - official HTML host track contract compatibility.
- Not guaranteed:
  - behavior of custom/forked hosts outside published contracts,
  - undocumented/internal development paths.

## Risk Notes for Users

- Expect rapid iteration and occasional behavior changes.
- Use pinned tag (`v0.1.0-alpha`) for evaluation; do not track `main` for stability.
- Prefer local test/sandbox scenarios before sharing outputs publicly.
