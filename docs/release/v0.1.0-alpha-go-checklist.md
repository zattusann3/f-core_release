# v0.1.0-alpha Go Checklist

Use this checklist for the first public release candidate.

Release positioning:

- Label: `v0.1.0-alpha`
- Public wording: `Developer Preview`
- Production use: `Not recommended`

## Release Intent and Messaging

- [ ] README clearly states: "Technical Preview / Developer Preview / non-production".
- [ ] Release notes include:
  - purpose (publish design philosophy),
  - scope (minimum core + minimum host),
  - non-goals,
  - known limitations.
- [ ] Support boundary is stated:
  - official HTML host is supported,
  - custom/forked hosts are best-effort or out of support.

## Functional Scope (Must Be Included)

- [ ] Core CLI runtime (validate/compile/run/trace).
- [ ] Minimum reference HTML host:
  - `docs/default-gui-host.html`
- [ ] Host handoff spec for optional say metadata:
  - `docs/host-handoff/lip-sync-meta.md`
- [ ] Bug report template is published and linked.
- [ ] Manual verification steps are published.

## Quality Gates (Go/No-Go)

- [ ] `deno task test:ci` is PASS on release commit.
- [ ] `deno task gate:gui-bridge` is PASS on release commit.
- [ ] CLI quick-start commands are re-verified on release commit.
- [ ] Minimum GUI path check (bridge JSONL path) is re-verified.

## Security and Operations

- [ ] Default posture is local/offline-first where possible.
- [ ] Development-only routes/channels remain disabled by default.
- [ ] Diagnostics policy is documented:
  - machine-readable errors preserved,
  - issue triage logs retained.
- [ ] Known safety constraints are listed in release notes.

## Packaging and Publication

- [ ] GitHub tag is created: `v0.1.0-alpha`.
- [ ] GitHub Release is the source of truth (canonical artifact).
- [ ] `main` remains development branch; user guidance points to tag.
- [ ] Website page is a guide/entry point and links to GitHub Release.
- [ ] Checksums / artifact list are attached (if binary/archive is published).

## Post-Release Response Plan

- [ ] First 48h: intake + first triage owner assigned.
- [ ] First 7 days: decide whether `v0.1.1` is required.
- [ ] Backlog labels are ready (`alpha-regression`, `docs-gap`, `host-gap`, `wontfix-alpha`).
