# Contributing Policy / コントリビューション方針

## Scope

- EN: This repository is maintained as a personal project for the author's own visual novel development.
- JA: このリポジトリは、作者自身のノベルゲーム開発のための個人プロジェクトとして運営されています。

## Issues

- EN: Bug reports and reproducible issue reports are welcome.
- JA: バグ報告や再現可能な Issue 報告は歓迎します。

## Pull Requests

- EN: Pull requests are generally not accepted.
- EN: Reason: the maintainer prioritizes progress for their own production workflow and cannot review/merge external changes continuously.
- JA: Pull Request は原則として受け付けません。
- JA: 理由: メンテナは自身の制作ワークフローを最優先しており、外部変更を継続的にレビュー・統合する運用を取れないためです。

- EN: Exception handling (if any) is fully at maintainer discretion.
- JA: 例外対応（もし行う場合）も、すべてメンテナ裁量です。

## Forks

- EN: Forking and private/public modification are welcome.
- JA: フォークおよび private/public を問わない改造は歓迎します。

- EN: Please follow the naming policy in `docs/BRANDING.md`.
- JA: 命名ポリシーは `docs/BRANDING.md` を参照してください。
